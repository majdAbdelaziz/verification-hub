# مركز التحقق — Verification Hub

موقع مركز التحقق للفحص الفوري لمطابقة التراخيص وكشف منصات الاحتيال المالي.

## هيكل الملفات

```
verification-hub/
├── index.html          ← الصفحة الرئيسية
├── algorithm.html      ← خوارزمية الفحص التفاعلية
├── ecosystem.html      ← المنظومة الرقمية 2026
├── contact.html        ← البلاغات والتواصل
└── blog/
    ├── index.html      ← قائمة المقالات
    └── article.html    ← صفحة المقال (تحمل الـ 6 مقالات عبر ?id=1-6)
```

## الرفع على GitHub Pages

1. أنشئ Repository جديد على github.com
2. ارفع جميع الملفات مع الحفاظ على نفس هيكل المجلدات
3. اذهب لـ Settings → Pages → Source: main branch
4. انتظر دقيقة — موقعك جاهز على https://username.github.io/repo-name

## ربط دومين مخصص (لاحقاً)

في إعدادات GitHub Pages، أضف Custom Domain ثم اضبط DNS لديك.
